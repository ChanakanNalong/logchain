### `src/alerts/alerts.service.ts`
- key ใหม่ `(OPEN, alert_type, source, batch_id, rule_id)` ตรงกับ index เป๊ะ
- `rule_id` มาจาก `dto.ruleId` หรือ `detail.rule_id` (detection ส่งเป็นตัวเลข เก็บเป็น string)
  ไม่มี rule (ML_ANOMALY, INTEGRITY_TAMPERED) = `IS NULL`
- เจอซ้ำ → `recordRepeat()`: `UPDATE ... SET occurrence_count = occurrence_count + 1, last_seen_at = now() RETURNING`
  บวกใน SQL ไม่ใช่ในแอป กันนับหายตอน alert มาพร้อมกัน · แพ้ race (23505) ก็นับเป็นซ้ำของตัวที่ชนะ
- ไม่รับ `occurrenceCount` / `lastSeenAt` จาก body ของ `POST /alerts`
- `findAll()` เรียงตาม `last_seen_at` แทน `created_at` — alert เก่าที่เพิ่งโดนซ้ำขึ้นมาบนสุด
