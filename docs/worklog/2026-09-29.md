## 2. บั๊ก: `sealBatch()` พร้อมกันสร้าง batch ผี → แก้แล้ว

เรียกพร้อมกัน (cron ทุกนาทีชน `POST /integrity/seal-now`) → ทุกตัวเห็น log ค้างชุดเดียวกัน → สร้าง batch หลายใบ
ใบแรกเขียน mapping ได้ ใบอื่นชน PK `log_batch_mapping` → เหลือ batch ไม่มี log · **ใบที่ anchor สำเร็จก่อนชนค้าง CONFIRMED** (เสีย gas ฟรี)

แก้: คิวใน process (`sealQueue`) ให้ seal ทีละครั้ง · ระบบรัน backend ตัวเดียวจึงพอ · หลาย replica ต้องใช้ Postgres advisory lock
