**แก้ถาวร (`2afc52e`):** `infra/tls/gen-certs.sh` ตั้งชื่อ CA `LogChain-Web-CA (<compose project>)`
(project: env → `.env` → `name:` ใน compose) · `bootstrap.sh` ส่ง `$PROJECT` ให้ · `trust-web-ca.sh` อ่านชื่อจาก CN ของ `ca.crt`
· CA ที่มีอยู่แล้วคงชื่อเดิม (สร้างใหม่เฉพาะตอนไม่มี `ca.key`)

- macOS / Windows ค้นชื่อแบบ substring — วงเล็บปิดกันชื่อใหม่ชนกัน แต่ CA **ชื่อเก่า** ยังไปโดนของ clone อื่น (Linux ไม่เป็น) · ยังไม่ได้ทดสอบบน macOS / Windows

- recall ของโมเดลต่ำกว่างานต้นฉบับ DeepLog (Du et al. 2017 · F1 ~0.96) มาก · ที่น่าสงสัย: ป้อน key เป็น `float` ตัวเดียวแทน embedding / one-hot
  · สัดส่วน train ต่างจากต้นฉบับ — **ยังไม่ได้ทดสอบ** · ไม่ได้แก้โค้ด (`detect.py` / `app/model.py` เหมือนเดิม)
