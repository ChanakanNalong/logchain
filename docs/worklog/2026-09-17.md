### สิ่งที่พบ: Trivy จับ `.env` ที่เป็น key=value ไม่ได้

ทดสอบ Trivy secret scanner กับ repo ที่ยังมีไฟล์ที่หลุดจริงอยู่ → **ไม่จับสักรายการ**
จับแต่ไฟล์ `.key` ที่ไม่ได้ track ด้วยซ้ำ แปลว่าต่อให้ตั้ง `exit-code: 1` ตั้งแต่แรก
ก็ไม่กันเคสที่เกิดจริง

ทดสอบ gitleaks กับไฟล์จำลองแบบเดียวกัน → จับครบ รวมถึง secret ที่ฝังในไฟล์ `.ts`
จึงวางเป็น 3 ด่านทับช่องว่างกัน: เช็คไฟล์ที่ถูก track → gitleaks → Trivy

gitleaks ตั้งให้สแกนเฉพาะไฟล์ใน tree ไม่ไล่ทั้ง history เพราะคอมมิตแรกสุดมี README template
ของ NestJS ที่ติด CI badge หน้าตาเหมือน token มาด้วย เป็น false positive ที่ลบย้อนหลังไม่ได้

| setting | เหตุผล |
