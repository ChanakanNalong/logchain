## 2026-09-23 — วันหลัก (39 commit)

### Alert และ detection
- **alert dedup** — alert ของ rule + host เดียวกันที่ยัง OPEN รวมเป็น `occurrence_count` (×N) แทนแถวใหม่ทุกครั้ง
- **เตือนซ้ำ** เมื่อ alert ยังเกิดต่อเนื่อง (`ALERT_RENOTIFY_MINUTES`)
- **Kafka outbox** — log ที่เข้าตอน Kafka ล่มเข้าคิว `kafka_pending_logs` แล้ว replay เอง · rule ใช้เวลาของ event ไม่ใช่เวลารับ
- **detection กัน event ซ้ำ** ด้วย `log_id` · **ตัดสินใจไม่เก็บ id ข้าม restart** (จะทำให้ rule นับขาด → brute force ไม่เด้ง)
- `kafka-python` 3.0.2 → 3.0.11 แก้ `Task is already done` (ยืนยันด้วย failover coordinator)

### Blockchain
- init RPC พังครั้งเดียวไม่ค้างทั้ง process แล้ว (retry backoff)
- guard `unhandledRejection` ของ ethers (ไม่ตาย + metric) · error อื่นยัง fail fast
- log แยก "รอ confirm ไม่ทัน" กับ "RPC timeout" · RPC error ระหว่างรอ receipt → UNVERIFIED ไม่ใช่ FAILED (ไม่เสีย gas ซ้ำ)

### Monitoring + แจ้งเตือน
- Prometheus: แก้ scrape ซ้ำ 2 target · **alert rule 13 ตัว** (service ล่ม · Postgres · Kafka broker · consumer ค้าง ·

- **Alertmanager → Gmail** (render config ตอน start · รหัสอยู่ในไฟล์ gitignored) · ทดสอบหยุด service จริง → ได้ email + resolved

### Backup และกู้คืน
