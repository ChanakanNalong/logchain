## A. หัวข้อ 4.6.6 การจำแนกสถานะของชุดข้อมูลก่อนบันทึกลงเครือข่าย (ฉบับปรับใหม่)

> วางแทนหัวข้อ 4.6.6 เดิม · สองย่อหน้าแรกกู้จากของเดิม (ยังถูกต้อง) · ย่อหน้าผลการประเมินเป็นของใหม่

นอกเหนือจากการตรวจจับในระดับรายการด้วย Rule Engine และระดับลำดับเหตุการณ์ด้วย DeepLog ระบบยังประเมินความผิดปกติในระดับชุดข้อมูล (Batch) ก่อนบันทึกค่า Merkle Root ลงเครือข่าย โดยใช้แบบจำลอง Isolation Forest ซึ่งเป็นวิธีตรวจจับความผิดปกติแบบการเรียนรู้ที่ไม่มีผู้สอน (Unsupervised Learning) อาศัยหลักการที่ว่าข้อมูลผิดปกติสามารถแยกออกจากกลุ่มได้ด้วยจำนวนการแบ่งที่น้อยกว่าข้อมูลปกติ คุณลักษณะที่ใช้จำแนกเป็นคุณลักษณะรวมของทั้งชุดข้อมูลจำนวนสิบตัว ได้แก่ จำนวน Log ในชุด จำนวนที่อยู่ IP ต้นทางที่แตกต่างกัน จำนวนแหล่งที่มาที่แตกต่างกัน จำนวนประเภทเหตุการณ์ที่แตกต่างกัน ค่าเอนโทรปีและสัดส่วนสูงสุดของการกระจายประเภทเหตุการณ์ สัดส่วนของเหตุการณ์ยืนยันตัวตนล้มเหลว สัดส่วนของเหตุการณ์ระดับความรุนแรงสูง สัดส่วนของเหตุการณ์ในขอบเขตข้อมูลบัตรชำระเงิน และอัตราการเกิด Log ต่อวินาทีในช่วงเวลาของชุดข้อมูล

การจำแนกในระดับนี้ต่างจากการตรวจจับด้วย DeepLog ในหัวข้อ 4.6.3 กล่าวคือ Isolation Forest ตอบคำถามว่าช่วงเวลาใดมีพฤติกรรมโดยรวมผิดปกติ ในขณะที่ DeepLog ตอบคำถามว่าลำดับเหตุการณ์ใดผิดปกติ ทั้งสองส่วนจึงทำงานคนละระดับและใช้ประกอบกัน ชุดข้อมูลทั้งที่จำแนกว่าปกติและผิดปกติจะถูกบันทึกขึ้นเครือข่ายเหมือนกัน โดยผลการจำแนกถูกเก็บกำกับไว้กับชุดข้อมูลในฐานข้อมูล การจำแนกจึงไม่มีผลต่อความสมบูรณ์ของหลักฐาน และหากส่วนตรวจจับขัดข้องหรือยังไม่ได้ติดตั้งแบบจำลอง การปิดชุดข้อมูลยังดำเนินต่อได้ตามปกติโดยผลการจำแนกเป็นค่าว่าง ซึ่งสะท้อนว่าการจำแนกระดับที่สามเป็นกลไกเสริม ไม่ใช่เงื่อนไขบังคับของการบันทึกหลักฐาน

การประเมินแบบจำลองใช้ชุดข้อมูลที่สร้างขึ้นจากการยิง Log ผ่านช่องทางรับ Log จริงของระบบในสภาพแวดล้อมทดสอบแยก แบ่งเป็นทราฟฟิกปกติจำนวน 【จำนวน batch ปกติ = n_train ___】 ชุดสำหรับฝึกแบบจำลอง และชุดสำหรับประเมินซึ่งประกอบด้วยชุดข้อมูลปกติ 【n_normal ___】 ชุด กับชุดข้อมูลที่จำลองการโจมตีสามรูปแบบ ได้แก่ การเดารหัสผ่าน (Brute Force) การสแกนพอร์ต (Port Scanning) และการโจมตีแบบปฏิเสธการให้บริการ (DoS) รวม 【n_attack ___】 ชุด ผลการประเมินได้ค่า Precision เท่ากับ 【precision ___】 ค่า Recall เท่ากับ 【recall ___】 และ F1-Score เท่ากับ 【f1 ___】 โดยมีอัตราการแจ้งเตือนเท็จ (False Positive ต่อชุดข้อมูลปกติ) เท่ากับ 【fp_rate ___】 เมื่อพิจารณาแยกตามรูปแบบการโจมตี แบบจำลองตรวจพบ Brute Force ได้ 【per_attack bruteforce recall ___】 Port Scanning ได้ 【portscan recall ___】 และ DoS ได้ 【dos recall ___】

อย่างไรก็ตาม ผู้พัฒนาระบุอย่างตรงไปตรงมาว่าตัวเลขข้างต้นได้จากสถานการณ์การโจมตีที่สร้างขึ้นเองผ่านกระบวนการทำงานจริงของระบบ (Controlled Evaluation) จึงมีน้ำหนักทางวิชาการน้อยกว่าการประเมิน DeepLog ที่ใช้ชุดข้อมูลมาตรฐาน HDFS ซึ่งกำกับป้ายโดยผู้เชี่ยวชาญและทำซ้ำเปรียบเทียบกับงานวิจัยอื่นได้ ผลนี้ยืนยันได้ว่ากลไกจำแนกความผิดปกติระดับชุดข้อมูลทำงานและแยกรูปแบบการโจมตีที่ออกแบบไว้ได้ แต่การยืนยันประสิทธิภาพกับทราฟฟิกจริงในองค์กรยังเป็นประเด็นที่ต้องศึกษาต่อ (หัวข้อ 5.7.3)
