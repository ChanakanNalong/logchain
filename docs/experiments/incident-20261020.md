## กลไกที่เกี่ยวข้อง
- **`trg_logs_no_update` (append-only)**: บล็อก `UPDATE logs` ตรง ๆ — การแก้ `message='hacked'` แบบไม่ disable trigger จึง **ล้มเหลว** (หลักฐานข้อ 06:39/06:40)
- **bypass**: `ALTER TABLE logs DISABLE TRIGGER …` (ต้องเป็น owner ของตาราง = role `logchain`) ก่อน UPDATE แล้ว ENABLE คืน — จึงแก้ `raw_hash` ได้
- **ตรวจจับ**: `verifyAllBatches` (cron ทุก 1 นาที) recompute ต่อแถว (`isRawHashIntact`) + Merkle root — `raw_hash` ที่เปลี่ยนทำให้ไม่ตรง snapshot/chain → `TAMPERED` + alert · **การ anchor บนเชน (merkle_root) ไม่ถูกแตะ** จึง recompute จับได้
